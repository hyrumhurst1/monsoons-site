# We sell AI visibility, so our own site invites every answer engine in.
# If we blocked these crawlers we could not credibly sell this.
#
# The distinction worth knowing, because it decides what is safe to block:
# training crawlers (GPTBot, Google-Extended, CCBot, Applebot-Extended) affect
# what a model knows. Retrieval crawlers (OAI-SearchBot, PerplexityBot,
# ChatGPT-User, Bingbot, Googlebot) affect what gets named in a live answer.
# The second group is the entire product. Never disallow one of those.
#
# One group per user-agent. There used to be two `User-agent: *` records, an
# Allow near the top and a Disallow at the bottom; a crawler that honours only
# the first matching group would have ignored the Disallow completely and the
# tuning page was reachable after all.
